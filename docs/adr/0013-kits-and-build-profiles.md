# ADR-013. Kits и профили сборки

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

«Конструктор» недостижим, если состав IDE меняется только сборкой (P19).

## Рассмотренные варианты

- Только ручная установка плагинов.
- Декларативные kits для L2/L3 в рантайме + cargo features для L1.

## Решение

Kit — TOML-файл с плагинами, ресурсами и настройками; применение идемпотентно; настройки kit — отдельный слой. L1 выбирается профилями сборки `app/kumiko` (ТЗ, раздел 15).

## Последствия

Сборку IDE можно передать одним файлом. Встроенные kits MVP: `minimal`, `java`.
