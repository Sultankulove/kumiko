# ADR-005. Language API = семантика LSP 3.17

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Нужен языковой API, не привязанный к Java, при этом совместимый с существующими серверами.

## Рассмотренные варианты

- Собственный языковой API.
- Семантика LSP 3.17 с generic-клиентом в ядре и middleware в языковом плагине.

## Решение

Generic LSP-клиент в kumiko-lsp; языковой плагин отвечает на `lsp/resolveLaunch` и перехватывает специфичные методы; сервер запускает Process Service (ТЗ, раздел 18).

## Последствия

Новые языки без изменения ядра. Editor получает результаты через сервис Language, не зная о LSP.
