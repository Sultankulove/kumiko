# ADR-015. Ресурсы L3: темы, иконки, локализация

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Токены тем без формата темы, UI на одном языке, нет иконок как данных (P24).

## Рассмотренные варианты

- Ресурсы внутри кода ядра.
- Пакеты данных с `resource.toml`, сервис Resources.

## Решение

Грамматики, темы, иконки, keymaps, сниппеты, l10n и kits — пакеты без кода, устанавливаются как плагины `kind = "data"` (ТЗ, раздел 21).

## Последствия

Все строки UI — через l10n (en, ru), все цвета и иконки — через токены темы.
