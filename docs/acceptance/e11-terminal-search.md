# Приёмка E11: Process, Terminal, Search

Этап E11 (ТЗ, раздел 28): PTY, kumiko-terminal-view, WASM-плагин terminal, полнотекстовый поиск, FileIndex. Критерии MVP 10 и 12. Проверка на **Windows и Linux** (ADR-020).

## Автоматически

| Тест | Что проверяет |
|---|---|
| `kumiko-process`: `pty::tests` | Процесс в псевдотерминале (ConPTY / Unix PTY), вывод, код возврата |
| `e11_terminal::a_shell_runs_in_a_terminal` | Shell в терминале ядра: ввод, вывод, `exit` закрывает сессию, `terminal.closed` с кодом 0 |
| `e11_terminal::the_terminal_plugin_opens_sessions` | WASM-плагин `kumiko.terminal`: команда `terminal.new` открывает сессию с shell из настроек |
| `e11_search::find_in_files` | Поиск по файлам: `.gitignore` соблюдается, регистр, regex с ошибкой, лимит, несохранённый текст открытых документов |
| `kumiko-search`: `text::tests` | Опции поиска, пропуск бинарных файлов, обрезка длинных строк |
| `kumiko-terminal-view` | Клавиши → байты xterm, цвета 16/256/true color |

## Вручную

| № | Действие | Ожидается |
|---|---|---|
| 1 | `Ctrl+Shift+F` | Всплывающее окно поиска, слово под кареткой выделено. Справа `Aa W .*`. |
| 2 | Набрать текст | Результаты появляются при наборе: строка с подсветкой совпадения, справа `файл:строка`. `Alt+C`, `Alt+W`, `Alt+X` переключают регистр, слово, regex. `Enter` открывает место (критерий 10, вместе с Quick Open из E7). |
| 3 | `Alt+F12` | Окно «Терминал», сессия «Локальный»: PowerShell на Windows, `$SHELL` на Linux, в папке проекта (критерий 12). |
| 4 | `dir` / `ls`, затем стрелка вверх | Вывод, история shell, курсор блоком. |
| 5 | Цветная программа (`git log --color`, `ls --color`) | Цвета ANSI. |
| 6 | `Ctrl+C` во время долгой команды | Прерывание. |
| 7 | `+` в заголовке окна | Вторая сессия «Локальный (2)». `×` закрывает сессию. |
| 8 | `exit` | Вкладка закрывается; последняя — окно скрывается. |
| 9 | Колесо мыши | Прокрутка истории; набор возвращает вниз. |
| 10 | `Ctrl+V`, `Ctrl+Shift+V` | Вставка из буфера обмена. |

На Windows шаги 1–3 и 4 (`dir`) пройдены 2026-10-17. Остальное и Linux — за владельцем.

## Отступления и отложенное

- До E13 (kits) плагин `kumiko.terminal` не ставится сам. Без него workbench открывает shell по умолчанию. ТЗ говорит: «отключение плагина убирает команды и панель». Это выполнится, когда kit `minimal`/`java` начнёт включать плагин.
- Выделение мышью в терминале нет. `Ctrl+Shift+C` копирует весь видимый экран.
- Бюджет «поиск по 50 000 файлов — первые результаты < 200 мс» не замерен. Поиск потоковый, первые результаты приходят до конца обхода.
- Широкие символы (CJK) в терминале не выравниваются по сетке точно.
