# ADR-012. Кодировка позиций: UTF-8 внутри

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

LSP использует UTF-16, Rust — UTF-8, Tree-sitter — байты (P13).

## Рассмотренные варианты

- UTF-16 везде.
- UTF-8 внутри, конвертация на границе LSP.

## Решение

`Position { line, character }`, где `character` — байт UTF-8 внутри строки. Конвертация в UTF-16 — только в kumiko-lsp; `positionEncoding` согласуется с сервером (ТЗ, разделы 12, 18).

## Последствия

Нет конвертаций на горячем пути редактора и подсветки.
