# ADR-017. Общие рантайм-хосты для JS/JVM/Python

- Статус: Proposed (после MVP)
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Процесс на каждый Node/JVM-плагин съедает бюджет памяти (P17).

## Рассмотренные варианты

- Процесс на плагин.
- Один хост-процесс на рантайм для всех его плагинов.

## Решение

Не принято. В MVP — процесс на плагин и WASM по умолчанию (ТЗ, раздел 17).

## Последствия

KPP не содержит Rust-специфики, чтобы общий хост можно было добавить позже без изменения протокола.
