# ADR-002. IPC: JSON-RPC 2.0 в бинарных фреймах

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Процессным плагинам нужен запрос-ответ, уведомления, отмена и бинарные потоки (PTY, большие данные) без base64.

## Рассмотренные варианты

- LSP-фрейминг `Content-Length` + JSON.
- gRPC/protobuf.
- JSON-RPC 2.0 в собственных бинарных фреймах с потоками.

## Решение

Фрейм: `length u32 LE | kind u8 | stream_id u32 LE (kind 1,2) | payload`, максимум 16 МБ; kind 0 — JSON-RPC, 1 — данные потока, 2 — закрытие (ТЗ, раздел 16). Кодек изолирован в kumiko-ipc.

## Последствия

Бинарные потоки без накладных расходов. MessagePack можно добавить как kind 3 без изменения методов. Требуется собственная реализация фрейминга и тесты E2.
