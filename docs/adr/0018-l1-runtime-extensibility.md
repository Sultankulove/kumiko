# ADR-018. Расширяемость L1 в рантайме (C ABI / WASM)

- Статус: Proposed (после MVP)
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

В MVP L1 заменяется только на этапе сборки.

## Рассмотренные варианты

- C ABI динамических библиотек.
- WASM-компоненты с доступом к рендеру.

## Решение

Не принято. Зависит от ADR-003 и open-question-4.

## Последствия

Трейты L1 (например, `EditorView`) проектируются так, чтобы их можно было позже вынести за стабильную границу.
