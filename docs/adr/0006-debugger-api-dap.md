# ADR-006. Debugger API = DAP

- Статус: Accepted (реализация после MVP)
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Отладчик вне MVP, но решение о API должно быть зафиксировано, чтобы не закрыть путь.

## Рассмотренные варианты

- Собственный API отладки.
- Debug Adapter Protocol.

## Решение

DAP-клиент в ядре, адаптеры декларируются плагинами (`contributes.debuggers`) по аналогии с языковыми серверами (ТЗ, раздел 19).

## Последствия

Java — через java-debug, GDB/LLDB — через их DAP-режимы. В MVP ничего не реализуется.
