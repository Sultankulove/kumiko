# ADR-007. Конфигурация: TOML + JSON Schema

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Настройки поставляют ядро и плагины; значения нужно валидировать и документировать.

## Рассмотренные варианты

- JSON с комментариями.
- TOML со схемами JSON Schema.

## Решение

Плоские ключи с namespace в TOML, слои defaults → kit → user → workspace → language; каждый ключ описан JSON Schema (ТЗ, раздел 22).

## Последствия

Невалидное значение — предупреждение и значение по умолчанию. Запись в чужой namespace запрещена.
