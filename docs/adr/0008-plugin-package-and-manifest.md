# ADR-008. Формат пакета плагина и манифеста

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Ядро должно показывать вклады плагина без его запуска и активировать его лениво.

## Рассмотренные варианты

- Регистрация вкладов кодом плагина при старте.
- Декларативный манифест `plugin.toml`.

## Решение

Плагин — каталог с `plugin.toml`: id, версия, `api`, `kind` (wasm | process | data), entry, permissions, activation, dependencies, provides/consumes, contributes, l10n (ТЗ, раздел 13).

## Последствия

Холодный старт не зависит от числа плагинов. Состояние enabled/disabled хранится вне каталога плагина.
