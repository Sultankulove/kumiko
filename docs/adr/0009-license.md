# ADR-009. Лицензия проекта

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Лицензия влияет на совместимость зависимостей и на возможность закрытых коммерческих плагинов (ТЗ, раздел 24).

## Рассмотренные варианты

- Apache-2.0 везде.
- Apache-2.0 для ядра, MIT OR Apache-2.0 для SDK и протокола.
- MIT OR Apache-2.0 везде.

## Решение

Apache-2.0 для всего репозитория (решение владельца, 23.09.2026). Совместимость зависимостей проверяет cargo-deny (`deny.toml`).

## Последствия

Патентный грант, закрытые плагины допустимы. Товарный знак и лицензия брендовых ресурсов решаются отдельно (раздел 31).
