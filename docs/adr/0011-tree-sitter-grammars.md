# ADR-011. Грамматики Tree-sitter: .so vs WASM

- Статус: Accepted для MVP (пересмотр после MVP)
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Грамматики — данные L3, но парсер Tree-sitter — нативный код.

## Рассмотренные варианты

- Нативная `.so`, загрузка через libloading с проверкой ABI.
- WASM-грамматики через wasmtime.

## Решение

В MVP — нативная `.so`, собранная в CI под целевой triple (ТЗ, раздел 18).

## Последствия

Максимальная скорость парсинга; грамматики привязаны к платформе. Пересмотр после MVP с учётом опыта Zed (docs/research/prior-art.md).
