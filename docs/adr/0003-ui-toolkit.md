# ADR-003. UI-тулкит

- Статус: Proposed (решается спайком E6)
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Rust GUI-тулкиты различаются зрелостью IME, доступности и производительности; ошибка выбора дорого стоит (ТЗ, разделы 20, 24).

## Рассмотренные варианты

- iced (MIT, wgpu).
- GPUI (тулкит Zed; лицензию и стабильность API проверить).
- gtk4-rs (LGPL, динамическая линковка) — запасной.
- Исключены: Tauri/Electron, Slint (лицензия), egui (immediate mode).

## Решение

Не принято. Спайк E6 измеряет кандидатов по порогам раздела 20: ≥ 60 fps прокрутки 10 000 строк, клавиша → пиксель p95 < 16 мс, Wayland и X11, IME, AccessKit/AT-SPI, лицензия, клавиатурная навигация, холодный старт < 300 мс.

## Последствия

Редактор и терминал в любом случае рисуются собственным виджетом на cosmic-text. До принятия ADR UI-крейты остаются заглушками.
