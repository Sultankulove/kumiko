# ADR-004. Владение документами в ядре

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Если буфер живёт в редакторе, при его замене или падении теряются правки, а LSP и плагины не видят несохранённый текст (P2).

## Рассмотренные варианты

- Буфер внутри Editor.
- Document Service в ядре, Editor — view/controller.

## Решение

Document Service (L0) владеет буферами (ropey), версиями, транзакциями и undo/redo; Editor отображает снимки и отправляет транзакции с `base_version` (ТЗ, раздел 12).

## Последствия

История и правки переживают замену view. Устаревшие правки ребейзятся, при конфликте — `ContentModified`.
