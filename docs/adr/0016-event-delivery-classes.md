# ADR-016. Классы доставки событий и resync

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Доставка at-most-once теряет `document.changed` и рассинхронизирует плагин (P21); шторм `fs.changed` блокирует систему (P8).

## Рассмотренные варианты

- Все события at-most-once.
- Все события без потерь.
- Два класса доставки.

## Решение

Класс A (состояние) — без потерь, с версиями; при переполнении очереди подписка отменяется и шлётся `$/resync`. Класс B (уведомления) — at-most-once с coalescing (ТЗ, раздел 11).

## Последствия

Плагин обязан уметь перечитать состояние. Тест модульности 11 проверяет resync.
