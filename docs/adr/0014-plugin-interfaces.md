# ADR-014. Межплагинные интерфейсы provides/consumes

- Статус: Accepted
- Дата: 2026-09-23
- Источник: ТЗ v1.0 ([docs/spec/kumiko-tz-v1.0.md](../spec/kumiko-tz-v1.0.md))

## Контекст

Командами и событиями нельзя выразить типизированный API между плагинами (P20).

## Рассмотренные варианты

- Прямые соединения плагинов.
- Версионированные интерфейсы, маршрутизируемые ядром.

## Решение

`[[provides]]`/`[[consumes]]` с semver и JSON Schema; вызов `service/call` → `service/invoke`; ленивая активация провайдера `onInterface:<id>` (ТЗ, раздел 14).

## Последствия

Потребитель не знает конкретного провайдера. Эталон MVP — `kumiko.git.repository`.
